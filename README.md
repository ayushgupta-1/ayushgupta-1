## 🚀 About Me

I am a **Staff Software Engineer** and **Founding Engineer** specializing in the architecture of high-scale, AI-integrated real-time platforms. Driven by a **"Systems First"** philosophy, I design self-healing, observable, and low-latency architectures that prioritize developer velocity and production reliability.

- 🔭 **Spearheaded Vooz Inc**: Built core infrastructure from zero to a global social platform serving **500k+ monthly active users (MAU)**.
- ⚡ **AI at Scale**: Migrated standalone models to a high-throughput **Triton Inference Server** cluster with dynamic batching achieving **1280+ RPS**.
- 🧠 **Edge Intelligence**: Engineered browser-local zero-latency inference using **ONNX Runtime (WebGPU/WASM)** and Cache API.
- 🔗 **Web3 Economy**: Architected Solana microservices with **Helius Webhooks** for atomic payment confirmations & real-time point balance hydration.
- 💬 **Ask me about:** Distributed Systems, Triton Inference Server, WebRTC Media Recovery, Next.js App Router, and Agentic AI/RAG Pipelines.
